# WP-00.1 — TenantStrategy contract extension

**Owner:** Claude Opus · **Phase:** v0 · **Depends on:** WP-00 + WP-05 (merged) · **Authorized contract change** (manager-approved 2026-08-13)

## Context

WP-05's read-only shape check found that the frozen `TenantStrategy` contract in
`packages/shared/src/strategy.ts` cannot represent parts of the operator's live strategy
document. The bidding engine's manual ceiling and placement-decrease cap currently have no
contract path — that gap blocks WP-01's real doctrine seeding. This WP widens the contract.
Widening only: every new leaf is OPTIONAL so `packages/strategy` defaults, WP-05 parity
goldens, and existing tests stay untouched.

## Spec — add homes for (names indicative; keep the contract's existing style)

1. Top level: `discovery.min_root_words`; `expanded_candidate_filter.{min_relevancy, max_sv}`.
2. `pacing`: three thresholds `{warn_above, act_above, underpace_below}` (keep
   `run_rate_tolerance` for back-compat as deprecated-optional) + `rank_cut_requires_operator`
   boolean.
3. `opt_groups` entries: `bid_floor_unit/value`, `bid_ceiling_unit/value`
   (unit enum e.g. absolute|pct_of_recommended — check the live doc SHAPE, never values),
   `placement_max_decrease`, `spend_share_max`, `preset`,
   `tacos_x_breakeven`, `tacos_x_breakeven_min`, `tacos_x_breakeven_max`.
4. `rank_lifecycle`: `graduate_weeks_stable` (weeks) alongside existing `dwell_days` —
   document the unit explicitly on both; `stepdown_cycles_min/max`, `regression_reescalate`.
5. `staged_apply`: `max_batches_per_run`, `cooldown_bypasses`, `tag_format`,
   `push_rank_min_days`, `priority_order`, `group_cadence`, `batch_unit`.
6. Wire-up notes (docs only, no code): a short section in `packages/strategy/README.md` (create
   if absent) mapping each new field to its consumer (bidding engine manual ceiling ←
   `opt_groups.bid_ceiling_*`; placement cap ← `placement_max_decrease`; WP-01 seeder must
   flatten the live doc's `management.*` nesting and rewrite the schema id).
7. Extend `contracts.test.ts` round-trip samples and the strategy tests to cover the new
   fields; confirm the no-numeric-leaf guard on `_local/strategy.TEMPLATE.json` still holds
   after you add the new keys (structure yes, numbers no).
