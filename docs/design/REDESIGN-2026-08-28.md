# Overnight UI/UX redesign — 2026-08-28

Directive: "Please just do the comparison by yourself. And truly improve the
ui ux." This pass compares against AdLabs screen anatomy (captures in the
2026-08-27 audit) and rebuilds composition, not just tokens.

## Dashboard

Before: a static KPI tile wall, two separate single-metric charts, then a
Flags card whose fifteen active flags at four lines each pushed everything
else off screen (full page ≈ 3200px tall).

After (≈ 2100px):

- **Cockpit** (`src/ui/cockpit.tsx`): the KPI tiles ARE the chart controls —
  AdLabs' optimizer anatomy. Up to two selected tiles (indigo underline for
  the first, orange for the second) drive a dual-axis trend whose axes carry
  the series colors. D/W/M granularity is honest: weekly/monthly buckets sum
  the base fields and derive ratios from the sums, never averaging daily
  ratios (pinned by `cockpit.test.ts`). Settling window shaded in-chart.
- **Top campaigns by spend**: a dense table with pipe-segmented campaign
  names, category chips (Rank/Profit/Shield/Discovery), spend-share bars,
  and derived ACOS — replaces nothing (this view didn't exist) and gives the
  dashboard an actual "where is the money going" answer.
- **Flags**: one scannable line per flag (severity chip · campaign ·
  quantitative headline) behind a native `<details>` disclosure; likely cause
  and the rule that fired expand on demand.
- **Honest coverage**: the settled-KPI window clamps to the first synced fact
  day; the subtitle says "(first synced day)" when the clamp bites (QA
  finding #14's UI half).

## Campaign Optimizer

The settled-tile grid (every label suffixed "(SETTLED)", every tile carrying
three lines of "No comparison data") and the fixed spend/sales chart are
replaced by the same Cockpit. It renders above the run-state branch, so an
operator gets performance context even when no recommendation run exists.

## Data Grid

The scroller now shows a styled, always-visible scrollbar — the table is
wider than any viewport on purpose, and without the affordance the clipped
columns read as a rendering bug. A right-edge fade + column pinning polish
remains on the follow-up list.

## Infrastructure fixed en route

- Dev preview DB moved to the transaction-mode pooler (6543): session mode's
  15-client cap kept exhausting from accumulated dev sessions and 500ing the
  app mid-iteration.
- **July fact partitions created** (`app.ensure_fact_partitions('2026-07-01', 1)`):
  the comparison backfill (Jul 12–Aug 11) would have failed loudly on insert —
  only the adlabs-backfill tool ensures partitions; the worker ingest path
  does not. Follow-up: worker should ensure partitions before ingest.
