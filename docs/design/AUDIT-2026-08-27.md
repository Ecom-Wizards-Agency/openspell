# Design audit — 2026-08-27 (Fable 5, prod screenshots on real data)

Scope: every route, dark mode, the pilot account (US marketplace), 1600×950. Screenshots
live outside the repo (client data). Ranked by user impact; each finding names the owning
surface.

## P1 — trust and correctness of what's shown

1. **Dashboard KPI deltas mislead.** "Sales $16,625 · ↓100.0% vs prior period ($167.97)"
   reads as a catastrophe. Either the delta compares the wrong grain (a day vs a period) or
   it faithfully reports the attribution-settling collapse of the last days — both are a
   presentation failure. Fix as one unit: (a) verify the comparison grain in
   `apps/web/app/dashboard/page.tsx` KPI assembly; (b) shade the trailing ~14 not-yet-
   settled days in every trend chart (lighter stroke / hatched band + "settling" note) so a
   sagging tail reads as attribution delay, not decline; (c) KPI deltas compare settled
   windows only. This is the single highest-trust fix in the product.
2. **Empty states dominate the Optimize section** (pre-WP-33). Full-width prose paragraphs
   floating in dark voids on /optimizer, /recommendations, /experiments. Standardize an
   empty-state card: eyebrow, one sentence, ONE action button, consistent max-width,
   vertical rhythm. Post-WP-33, "ran — nothing to propose" must render distinctly from
   "never ran" (run timestamp + narrative).

## P2 — brand system adoption (the "looks horrible" fix)

3. **Palette is generic slate, not the brand.** Adopt Brand Guides V2.3 tokens into the
   `--wa-*` custom properties (`apps/web/src/ui/theme.css`, `packages/ui`): surfaces
   Obsidian `#0F1318` / Carbon `#171C24` / Slate `#2A323D` borders; text Cloud `#F5F6F8` /
   Mist `#9AA5B4`; accent = **Signal Orange `#FD4807`** (one per view); data/selection =
   Electric Indigo `#3322E0`; semantic `#22C55E`/`#EF4444`; Ruby Red never in UI.
4. **One primary action per view.** Today multiple blue buttons compete (Filter, Open
   review, New experiment). The view's single primary becomes the orange (gradient) button;
   everything else ghost/outline. Map per route in the spec.
5. **Typography.** Ship Inter (variable) via `next/font`, `font-variant-numeric:
   tabular-nums` on every table/KPI number, tighter display tracking on page titles,
   consistent type scale (eyebrow 600 caps / title 700 / KPI value 800).
6. **Charts off-brand and under-designed** (`apps/web/src/ui/viz.tsx`): series → indigo,
   highlighted/current → orange, comparison/rest → `#868A96`; fewer gridlines; larger tick
   type; endpoint value labels instead of floating tooltip-only; ACOS line contrast on dark
   fails now. Follow the repo dataviz conventions when implementing.

## P3 — surface-specific

7. **Topbar**: "signed in as victor@ecomwizards.ag…" truncates and eats width → compact
   avatar menu (initials chip → dropdown w/ email + sign out). Theme toggle icon is a lone
   glyph with no affordance.
8. **Roster (/settings/profiles)**: 50 per-row Save buttons; move to dirty-row tracking +
   one sticky save bar (pattern exists in roster-bulk). Filter bar wraps awkwardly at
   1600px; align to a single row grid.
9. **Grid toolbar** crowds (filter builder + group-by + columns + export + views in one
   line): two-row toolbar — filters row, table-controls row right-aligned.
10. **Feedback tracker**: raw inline `<select>+input+Save` per card → compact admin
    controls; votes chip styling; card grid max-width. (Bug board arrives with WP-35; use
    the roadmap column pattern.)
11. **Sidebar**: footer tagline cramped against Collapse; group labels fine; active-item
    treatment should use indigo-soft background + orange left rule (brand), not blue tint.
12. **Roadmap/board cards**: vote chips oversized relative to titles; "feature" tag adds
    noise on every card — show only non-default types.
